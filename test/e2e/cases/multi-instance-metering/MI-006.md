## 目的
DB 抖动（连接挂起不拒绝）跨 sync 周期后恢复，总量精确（全称不变量；P0 回归）
## 前置
G-fault；流量进行中对 postmaster SIGSTOP
## 步骤
1. 双实例发已知用量，期间 SIGSTOP postmaster 持续 ≥2 个 sync 周期
2. SIGCONT 恢复
3. poll 两实例新水位行出现（抖动期增量补推）
4. 读 DB 累计值
## 预期
- 累计值 == Σ 全部响应 usage（精确，不丢失不翻倍）
- 抖动期请求的判定口径不要求实时一致（协议语义）
