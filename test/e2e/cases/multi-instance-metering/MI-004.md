## 目的
kill -9 后同 instance_id 重启，已上推的量不被重复入库（水位行重放只恢复镜像）
## 前置
G-base；run 唯一 fixture key
## 步骤
1. gw-a 发已知用量 → poll gw-a 水位行（全部增量已 commit）
2. kill -9 gw-a → 同 id 重启（重新 spawn 同 instance_id 配置）
3. 等待一个 sync 周期，读 DB 累计值
4. gw-a 再发新增量 → poll 水位行 → 读 DB
## 预期
- 步骤 3：累计值与步骤 1 完全一致（不重复入库）
- 步骤 4：累计值 == 步骤 1 + 新增量（不丢失）
