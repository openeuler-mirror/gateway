# 角色视图：前期试用者（Trial User）

> 本文档是 [`cases/`](../cases/) 共享用例库的**引用视图**，不含用例内容。
> 执行时对照 `cases/` 中对应 ID 的步骤与预期。格式与取用规则见 [`README.md`](../README.md)。

## 角色定位

- **适用对象**：少量前期试用的真实用户（开发/业务人员），不要求了解网关内部
- **测试目的**：验证真实使用路径顺畅、自己可对账、可感知功能价值
- **预计工作量**：约 60~90 分钟（含等待窗口恢复的时间）
- **需要的支持**：一名客户侧/我方运维人员配合执行 admin 角色用例（见文末"协作说明"）

## 前置条件

开始前请确认你已拿到：

1. **网关地址**：`http://<gateway-host>:4000`
2. **API key 明文**（管理员通过 ADM-01 创建并交付，只显示一次，请妥善保存）
3. **你被授权的模型名列表**与各模型**单价**（USD / 百万 token，输入价 + 输出价）
4. **你的套餐限额**（RPM / TPM / 并发 / 终身额度，用于 QTA 系列）
5. 已知你的 key 前缀（若管理员设置了，用于对账时识别）

工具：终端 + curl（本文用例均给出 curl 命令）；可选 openai / anthropic SDK。
